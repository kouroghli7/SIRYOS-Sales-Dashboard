# 📊 SIRYOS – Sales Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing SIRYOS sales data through an interactive Business Intelligence dashboard developed using Microsoft Power BI.

The dashboard provides a comprehensive overview of sales performance, enabling better monitoring of business activities and supporting data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor key performance indicators (KPIs).
- Track sales trends and evolution.
- Analyze sales by product and customer.
- Identify business performance insights.
- Facilitate strategic decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Measures and calculated indicators.
- **SQL** – Data extraction and querying (if applicable).

## 📈 Dashboard Features

- Sales performance overview.
- Interactive visualizations.
- Dynamic filters and slicers.
- Sales trend analysis.
- KPI monitoring.
- Detailed business analysis.
